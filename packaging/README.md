# 4398 教师运行包

请将整个 ZIP 解压到一个文件夹，再双击 `start.cmd`。程序会使用包内 Java 启动网站，并自动打开浏览器，无需安装 Node.js、Java、IDEA 或 MySQL。

登录账户为 `admin`，密码为 `123456`。右上角可以切换数据库中已有的账户。按启动窗口中的回车键停止服务；端口已被其他程序占用时，启动器会改用相邻的空闲端口。

## 网络与数据

本运行包连接项目原有的课程数据库，沿用其中的账户、游戏和记录。它不是数据库快照，操作会写入同一数据库。

AI 客服和宠物使用包内配置的百炼服务。文字和图片问答都需要联网，且依赖密钥有效、应用权限和剩余额度。植物大战僵尸及关卡编辑器首次打开时需要联网加载 CheerpJ，美式八球和小丑牌直接使用包内资源。

如果学校数据库只能在校园网或指定网络访问，请先接入相应网络。无法连接数据库时，网站无法完成启动；运行包不能绕过数据库或云端服务的访问限制。

## 文件说明

- `app/4398.jar` 包含后端、网页和游戏发布资源
- `runtime/` 是随包提供的 Java 21 运行环境，保留原有许可证文件
- `config/application-local.properties` 保存本次交付使用的连接配置
- `logs/` 保存启动及运行日志
- `data/` 保存本包产生的附件和 AI 用量记录
- `delivery.json` 记录版本、运行环境来源与校验值

此包包含实际数据库与 AI 凭据，只交给获准使用的老师或组员，不要公开上传。删除或过期的密钥需要由提交者更新配置并重新打包。

出现问题时，先查看 `logs/startup-output.log` 和 `logs/startup-error.log`。不要把包含连接信息的日志公开发布。
