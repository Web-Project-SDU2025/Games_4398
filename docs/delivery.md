# 教师运行包

[返回项目说明](../README.md)

开发者在项目根目录双击 `package.cmd`，或执行：

```powershell
.\package.cmd
```

打包机需要 JDK 21、Node.js，以及可用的 `application-local.properties`。工具会构建网页、两款游戏和后端，从 Adoptium 官方下载 Java 21 运行环境并校验 SHA-256。工具会先启动交付副本，检查业务读取以及真实文字、图片 AI，通过后才在 `dist/` 生成 ZIP 和校验文件。同版本输出已存在时，工具停止处理，不覆盖原文件。

运行包包含实际数据库密码和百炼密钥，只能交给获准使用的老师或组员。`dist/` 不进入源码 Git 提交；交付时发送生成的 ZIP，不要只发送后端 JAR。源码中的打包工具没有内置密钥。

教师将整个 ZIP 解压后双击 `start.cmd`，不需要安装 Java、Node.js、IDEA 或 MySQL。启动器使用包内 Java，只监听本机地址；端口被占用时改用相邻端口，不关闭其他服务。

## 功能条件

网页、八球和植物大战僵尸素材都在运行包中。课程数据库仍是线上原数据库，老师需要能访问该数据库的网络；账户、游戏资料、消息和资金操作会影响同一数据库。

AI 客服、宠物与图片问答沿用本机配置的百炼应用，仍依赖网络、密钥、应用权限和剩余额度。Java 游戏及关卡编辑器首次打开时需要联网加载 CheerpJ。打包不能替代这些在线服务，也不能保证密钥过期或服务不可用后继续工作。

运行包使用独立生成的 JWT 密钥，不复用开发环境的登录签名。构建时临时进入 JAR 的开发配置会从交付副本中移除，运行时只读取 `config/application-local.properties`。

## 交付检查

开发者可使用下面的命令在独立端口验证已生成的运行目录：

```powershell
.\scripts\Test-Delivery.ps1 -PackageDirectory ".\dist\4398-teacher-1.12.16-windows-x64"
```

检查会启动包内 Java，读取首页、游戏清单、账户、消息和商城，并真实调用一次文字问答及一次图片问答，结束后停止本次服务。它不会修改游戏资料或操作资金，但真实 AI 请求会消耗少量额度。该检查不等同于在老师电脑和网络上完成完整人工试玩。
