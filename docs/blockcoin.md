# 字块币与游戏商城

[返回项目说明](../README.md)

字块币（Blockcoin）是平台内使用的整数货币。账户首次使用商城时会获得 100 字块币。植物大战僵尸和美式八球售价均为 100 字块币。管理员可在游戏资料中设置每次正式通关的奖励，范围为 0–1000，0 表示不发奖励；植物大战僵尸的初始配置为 15，重复通关也会获得奖励。服务器在开局时保存金额，之后的配置修改只影响新局。美式八球仍按本局成就与单人获胜规则结算，不使用关卡通关奖励字段。

美式八球中，玩家 1 对应登录账户。玩家 2 在单人模式下由电脑控制，在双人模式下由本地对手操作。两种模式的成就奖励只计入玩家 1 的账户，每项每盘一次，犯规杆不发成就奖励。

服务器在对局中记录已解锁成就，分出胜负后将成就和获胜奖励合并入账，只保存一笔流水并发送一条到账通知。玩家输掉比赛也会获得本盘已解锁的成就奖励。中途重开或退出的未完成对局不结算，重复提交终局结果不会重复发奖。

| 成就或结果 | 奖励 |
| --- | ---: |
| 开门红 | 1 字块币 |
| 一杆双收 | 4 字块币 |
| 翻袋好球 | 6 字块币 |
| 连下三城 | 8 字块币 |
| 一杆三收 | 11 字块币 |
| 勾球进袋 | 11 字块币 |
| 单人模式击败电脑 | 20 字块币 |

双人获胜、电脑获胜和中途重开不产生获胜奖励。单人模式中，电脑提前进八号等规则判负也属于玩家获胜。服务器保存每盘模式和随机先手，接收单杆球号证据后重新计算球组、轮次和成就；金额不读取客户端提交值，同一业务编号只入账一次。客户端证据不是服务端物理重放，不能用于声称已具备完整反作弊能力。

用户可以在商城搜索和筛选游戏，并查看最近二十笔收支。购买后的游戏会保留在游戏库中，用户可以单独调整收藏状态。

管理员可以使用关卡编辑器制作和试玩关卡。正式关卡会按规则发放奖励，试玩关卡不发奖励。

## 记账规则

后端负责核定商品价格和奖励，并记录初始发放、购买、通关奖励及管理员调整。重复提交不会重复记账，余额、游戏归属和收支记录会一并更新。

游戏开始后，平台会建立游戏会话并记录游玩时间与关卡结果。后端会核对游戏归属和正式关卡，再处理通关奖励。

正式通关记录与奖励会一并保存。网络请求重试不会重复发奖；浏览器异常退出或长期断网时，平台会保留最近一次心跳时长，并在会话超时后将结果记为未通过。

普通 Java 游戏会记录游玩时长；需要上报关卡结果的游戏通过适配器接入。试玩和自定义关卡可以保留游玩记录，但不发放奖励。

用户可以在游戏库的字块币足迹中查看收支结果。切换账户后，平台会读取新账户的余额和记录。

管理员可以按账户、收支方向、原因和日期查询流水，也可以注明原因后调整账户余额或撤回游戏。收回金额不能超过账户余额，单个账户最多持有 20 亿字块币。

管理员撤回游戏不会退款，购买流水、收藏和历史记录都会保留。用户重新购买时会产生新的购买记录。

用户隐藏游戏记录时，平台只调整列表显示状态；原分数、时长、关卡结果和奖励仍会保留并参与首页统计。

账户创建、资料或角色变更、字块币变动和游戏库变更会触发站内通知。管理员发布的公告对所有账户可见，每个账户单独记录已读状态。

## 文件职责

平台后端负责余额、流水、游戏会话、奖励和权限校验；前端负责商城、账户管理、游戏库足迹和消息界面。数据表结构与初始化方式见[数据库说明](../database/README.md)。
