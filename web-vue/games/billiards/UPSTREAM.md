# 美式八球来源

本游戏从本地 `D:\RJGC\Billiards-main` 迁入，原仓库为 [Web-Project-SDU2025/Billiards](https://github.com/Web-Project-SDU2025/Billiards)。迁入内容包含本地已完成的物理、界面、成就和性能修改。

当前发布版本使用 Canvas、JavaScript 和 Matter.js 0.20.0，在浏览器中直接运行。碰撞检测、穿透修正和冲量求解由 Matter.js 完成，台呢滑动与滚动摩擦、双人规则、判罚和六项成就由本项目维护。平台复用原有商品入口和游玩计时协议，八球不加载 CheerpJ。

平台版本另增单人电脑对抗、服务器随机先手及字块币奖励。电脑使用几何路线选择和原生物理预演，预演只操作独立副本，并在正式出杆前加入小幅误差。服务器奖励仅存在于 4398 平台，原桌面工程不接入账户或账本。

球台和球体 PNG 由原 Java 绘制器生成，商城封面来自游戏实际画面。两个 WAV 音效来自课程示例，来源说明保留在 `AUDIO-SOURCE.txt`。Matter.js 的 MIT 许可保留在 `MATTER-LICENSE.txt`。

开发者在 `web/` 维护当前运行代码和素材，在 `tests/` 维护规则、物理、渲染和电脑控制测试。`main.mjs` 负责输入与帧循环，`computer.mjs` 管理电脑回合与后台线程，`hud.mjs` 更新比赛文字和球组托盘。

迁移时保留的 Java 参考副本已清理，独立桌面工程仍位于迁入来源目录。平台共用运行器保留在 `games/runtime/`，账户、奖励和数据库业务仍由 Java 后端处理。

迁入工程未附带独立的上游软件许可文件，本说明只记录来源，不新增或替代上游授权。
